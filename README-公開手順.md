# 観戦者にリアルタイム公開する手順

## 1. サーバーを起動 (Node.js 18 以上が必要)
```
cd このフォルダ
node server.js
```
起動すると URL と **管理者パスワード** が表示されます (初回のみ自動生成され `data/admin-password.txt` に保存)。
自分で決めたい場合: `ADMIN_PASSWORD=好きな文字列 node server.js`

## 2. 使い方
- **観戦者**: 表示されたURLを開くだけ。閲覧専用で、勝敗・設定は変更できません (サーバー側で拒否されます)。
- **あなた(主催者)**: 同じURLを開き、右上の「🔒 管理者ログイン」でパスワードを入力。以降は通常どおり編集でき、変更は観戦者へリアルタイムに反映されます。
- 観戦URLは 設定 → 「配信」タブ → 「観戦URLをコピー」。

## 3. 同じWi-Fi外の人に見せる
- ターミナルに出る `http://192.168.x.x:8080/` は同じWi-Fi内のみ。
- インターネット越しなら、次のどちらか:
  - トンネル: `cloudflared tunnel --url http://localhost:8080` などで発行されたURLを配る
  - ホスティング: Render / Railway / Fly.io などに、このフォルダを Node アプリとしてデプロイ (`npm start`)。環境変数 `ADMIN_PASSWORD` を必ず設定。
- 公開時は必ず **https** のURLを使ってください (パスワードが暗号化されます)。

## 補足
- 大会データは `data/state.json` に保存され、サーバーを再起動しても残ります (無料ホスティングの一部は再起動で消えます)。
- 配信画面 (`?display=1`) もサーバー経由で動くので、別PCやOBSのブラウザソースでも連動します。
